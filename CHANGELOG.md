# Changelog

All notable changes to this project will be documented in this file. The
project follows Semantic Versioning after the first stable release.

## Unreleased

### Added

- Immutable typed HTTP and WebSocket fault definitions.
- Explicit feature registries with deterministic composition.
- Registry-bound FastAPI routers with `raises`, `handshake_raises`, and
  `closes` contracts.
- RFC 9457 runtime handling for domain and framework errors.
- OpenAPI 3.1 response and schema generation with conflict detection.
- Opt-in runtime/OpenAPI and undeclared-fault testing helpers.
- CPython 3.12, 3.13, and 3.14 compatibility gates.
- MIT license and distribution metadata.
